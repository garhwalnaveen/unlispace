# Orbit visual direction

Resend's installed design skill informs the black/white palette, neutral borders, restrained
surfaces, sentence case, and clear type hierarchy. Orbit retains its own logo and artwork.
Marketing is always dark; the workspace and native app retain explicit appearance choices.
The landing page uses a display serif stack, while product screens use system UI fonts.
Domaine and Favorit are not bundled; the project has no license for those font assets.
